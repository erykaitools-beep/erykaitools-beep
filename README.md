# Eryk — AI automation and agent systems

I originate and direct independent AI projects, from defining the problem
to coordinating implementation, checking evidence and deciding what to release.
My work uses AI-assisted development; each project makes its scope,
limitations and available evidence explicit.

I am interested in opportunities around AI automation, agent systems and
AI-assisted product development. These projects show the work behind that interest.

## How I approach the work

- Define the intended behavior and constraints before adding more features.
- Keep runtime behavior, test results and future plans distinct.
- Make failures inspectable through logs, replay, regression tests or incident analysis.
- Publish limitations and negative results alongside working demonstrations.
- Credit AI assistance and distinguish my project direction from model-generated implementation.

Technologies used across the projects include Python, JavaScript, local-model
integration, JSONL persistence, pytest, Playwright and GitHub Actions.
